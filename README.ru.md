# Beseda

[![PyPI](https://img.shields.io/pypi/v/beseda)](https://pypi.org/project/beseda/) [![CI](https://github.com/mikhail-angelov/beseda/actions/workflows/ci.yml/badge.svg)](https://github.com/mikhail-angelov/beseda/actions/workflows/ci.yml) [![Python](https://img.shields.io/pypi/pyversions/beseda)](https://pypi.org/project/beseda/) ![macOS Apple Silicon](https://img.shields.io/badge/macOS-Apple%20Silicon-black?logo=apple) [![License: MIT](https://img.shields.io/badge/license-MIT-blue)](https://github.com/mikhail-angelov/beseda/blob/main/LICENSE)

**Голосовой разговор с ИИ-агентом.** Скажите «Вика, …» и разговаривайте с агентом по-русски или по-английски прямо из терминала:
распознавание и синтез речи работают локально на Mac, агент работает в текущей папке.

[English version](README.md)

![Демо Beseda: обращение, вопрос с выполнением команд, пауза, уточнение, стоп](docs/demo-ru.gif)

▶ [Тот же разговор со звуком (MP4)](docs/demo-ru.mp4). Фразы пользователя произносит второй голос Silero вместо
микрофона; распознавание, агент pi и ответы — настоящее приложение. Долгие ожидания в GIF сокращены.

```
микрофон → Silero VAD + whisper.cpp (локально) → мозг: агент pi, Codex или DeepSeek → синтез: Silero (локально) → динамики
```

> **Статус:** альфа. Только macOS на Apple Silicon. Русский (по умолчанию) и английский; новый язык — это один TOML-файл.

## Возможности

- **Слово активации, как у умной колонки.** В модель уходят только фразы с обращением «Вика»; после ответа можно
  продолжать без него, «стоп» завершает разговор, «подожди» даёт время подумать.
- **Локальная речь.** whisper.cpp на GPU Mac (Metal) для распознавания, Silero для синтеза: от первого слова
  ответа до звука 0,1–0,25 с.
- **Подключаемые «мозги».** Агент [pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) (читает и
  правит файлы, запускает команды), [Codex](https://github.com/openai/codex) или обычный чат с DeepSeek;
  другой агент добавляется одним классом.
- **Работает, когда играет музыка или видео.** Эхоподавление macOS (как в FaceTime) убирает звук динамиков
  из микрофона; громкость других приложений не меняется.
- **Наблюдаемость.** Каждая сессия пишет лог с хронологией задержек каждого хода: распознавание, первый токен,
  первый звук, вызовы инструментов.
- **Запись диалога.** Весь разговор в одном WAV, с реальными паузами.

## Требования

- macOS на Apple Silicon, Python 3.12+, [uv](https://docs.astral.sh/uv/), `brew install portaudio`
- Для `--tts edge`: `brew install ffmpeg`
- Для мозга по умолчанию: `npm install -g @earendil-works/pi-coding-agent` и ключ DeepSeek в настройках pi.
  Для `--brain codex`: [Codex CLI](https://github.com/openai/codex) с выполненным `codex login`; модель берётся
  из `~/.codex/config.toml`, если не задан `--model`.
  Для `--brain deepseek`: переменная окружения `DEEPSEEK_API_KEY`.

## Установка

```bash
brew install portaudio
uv tool install beseda
```

Модели скачиваются при первом запуске в `~/.beseda/models/` (Whisper small ~490 МБ, Silero ~145 МБ, VAD ~1 МБ).

## Использование

```bash
cd ~/some/project   # агент работает в текущей папке
beseda                      # по-русски
beseda --language en        # по-английски
```

В таблице русские фразы; у английского пакета свои («Alice, …», «hold on», «that's all»).

| Вы говорите | Что происходит |
|---|---|
| «Вика, какая погода?» | Начинается разговор (звук Tink), в модель уходит «какая погода?» |
| «Вика» | Сигнал и ожидание запроса |
| что угодно в течение `--follow-up` с после ответа (8 с) | Уходит в модель без обращения; в строке статуса обратный отсчёт |
| «Подожди», «дай подумать», «секунду» | В модель не уходит; ожидание продлевается до `--hold` с (2 мин) |
| «Стоп», «хватит», «спасибо, всё» или тишина | Разговор завершён (звук Bottle), снова нужна «Вика» |
| что угодно без обращения | Игнорируется, показывается серым |

Клавиши: **Пробел** — микрофон вкл/выкл, **Esc** — перебить ответ, **q** — выход.

Пока ассистент говорит, микрофон выключен, чтобы он не слышал сам себя; перебить голосом пока нельзя.
Пока Beseda запущена, системный индикатор микрофона горит: поток должен быть открыт, чтобы услышать слово активации.

## Настройки

Любую опцию можно задать в `~/.beseda/config.toml`; флаги командной строки важнее.

```toml
language = "ru"           # ru | en | свой пакет
brain = "pi"              # pi | codex | deepseek
model = "deepseek/deepseek-v4-flash"
whisper = "small"         # small | turbo
vocabulary = ["JavaScript", "DeepSeek"]
tts = "silero"            # silero | edge | say
voice = "baya"
wake-word = "вика"        # по умолчанию из языкового пакета; "" — отвечать на всё
follow-up = 8
hold = 120
record = true             # или путь к файлу
log-days = 14
```

Полный список: `beseda --help`.

## Языки

Всё, что зависит от языка разговора, лежит в языковом пакете — TOML-файле: язык и подсказка для Whisper,
голосовой промпт для модели, слово активации и его окончания, стоп-фразы и фразы паузы, голоса по умолчанию
и модель Silero, строки интерфейса.

Встроенные пакеты: [`ru`](beseda/languages/ru.toml) (по умолчанию) и [`en`](beseda/languages/en.toml). Чтобы изменить
пакет или добавить язык, положите файл в `~/.beseda/languages/`: `ru.toml` там заменяет встроенный, `de.toml`
добавляет немецкий (`beseda --language de`). Начните с копии встроенного пакета; все ключи обязательны.

## Распознавание речи

Приёмы из [Vadic](https://github.com/mikhail-angelov/vadic), проверенные на реальных диалогах: нормализация
громкости перед распознаванием, VAD внутри Whisper (без него кашель превращается в «Спасибо.», а это стоп-фраза),
подсказка-образец стиля для пунктуации и `vocabulary` для терминов, жадное декодирование при температуре 0.

| `whisper` | Время на фразу (M1) | Заметки |
|---|---|---|
| `small` (по умолчанию) | ~0,5 с | Иногда путает слова |
| `turbo` (large-v3-turbo-q5_0) | ~2,1 с | Заметно точнее; 574 МБ |

Модели, уже скачанные другими приложениями (VoiceInk, Vadic), используются повторно.

## Синтез речи

| `tts` | Русские голоса | Английские голоса | Где | На предложение (ru) | Процессор на 1 с речи | Память |
|---|---|---|---|---|---|---|
| `silero` (по умолчанию) | xenia, baya, kseniya, aidar, eugene | en_0 … en_4 | локально | 0,04 с (en: ~0,35 с) | 16 мс | ~760 МБ |
| `say` | Milena | Daniel | локально (macOS) | 0,6 с | 140 мс | ~40 МБ |
| `edge` (экспериментально) | ru-RU-SvetlanaNeural, ru-RU-DmitryNeural | en-US-AriaNeural, en-US-GuyNeural | облако Microsoft | 1–2 с | 60 мс | ~55 МБ |

Русская модель Silero пропускает цифры и латиницу, поэтому русский голосовой промпт просит модель писать числа
и названия русскими словами. Сравнить голоса на слух: `beseda-samples [--language en]` озвучивает одну фразу
всеми голосами в `~/Downloads/beseda-tts-samples/`.

## Логи и записи

Каждая сессия пишет лог `~/.beseda/logs/beseda-<время>.log`; логи старше `log-days` удаляются при запуске.

```bash
grep summary ~/.beseda/logs/*.log | tail      # задержки по ходам: stt, llm_first_token, tts_first_audio, voice_to_voice
grep -E 'ERROR|WARNING' ~/.beseda/logs/*.log   # инциденты
```

`--debug` добавляет все события pi. `--record` сохраняет диалог в `~/Downloads/beseda-<время>.wav` при выходе.

## Безопасность

С мозгом `pi` по умолчанию у агента **полный доступ**: по голосовой команде он читает и пишет файлы и выполняет
команды в текущей папке. С `codex` команды выполняются без подтверждений в песочнице Codex workspace-write:
менять можно только текущую папку, а у команд нет сети. Распознавание ошибается. Запускайте Beseda только там, где это допустимо, и держите
такие папки под контролем версий.

## Приватность

- Распознавание, синтез через `silero` или `say`, логи и записи остаются на вашем Mac.
- То, что вы говорите ассистенту (после слова активации), уходит провайдеру LLM: по умолчанию DeepSeek, с `codex` — OpenAI.
- С `tts = "edge"` ответы уходят в Microsoft.
- Логи содержат полный текст диалогов, включая фразы, обращённые не к ассистенту; хранятся `log-days` дней.

## Расширение

- Мозг (`beseda/brains.py`) отдаёт события `("text", …)`, `("tool", …)`, `("error", …)` и умеет `abort()`;
  регистрируется в `BRAINS`.
- Движок синтеза (`beseda/tts.py`) — наследник `PcmEngine` с методом `render(text) -> PCM`; регистрируется в `TTS_ENGINES`,
  а его голоса перечисляются в `[voices]` каждого языкового пакета.
- Язык — это TOML-файл, см. [Языки](#языки).
